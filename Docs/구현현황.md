# tato.exe 구현 현황

> 기준: 통합 기획서 v0.5 / v0.6 + 적 설계 문서
> 범위: 런처 셸 · 씬 전환 · MVP 전투 코어 · 런(맵) 구조 · 덱/컬렉션 · 대장간 · 아트 적용 구조

---

## 1. 한눈에 보기 — 현재 돌아가는 루프

```
[런처]  홈 GAME START
   │   (DOS 로딩 연출 + 해상도 전환)
   ▼
[전투 씬]  1노드 ─ 2노드 ─┬─3─┬─4… ─ 7 대장간 ─ 8 ─ 9 휴식 ─ 10 보스
   │                     └───┘  (분기 · 노드 직접 선택)
   │   전투 승리 → 보상(토인 + 카드 3장 중 1택) → 맵으로
   │   보스 격파 → 다음 스테이지(배경 전환) → … → 3스테이지 보스 = 런 클리어
   │   패배      → 인게임 덱 소멸(귀속 제외) → 런 종료
   ▼
[런처]  토인·감자창고·덱 수치가 갱신되어 이어짐
```

## 4. 씬 전환 시스템

미니게임마다 해상도가 달라 창 크기가 바뀌는 경우의 시퀀스를 구현.

```
① 오버레이 페이드 인 (0.3초) — 화면을 완전히 가림
② 가려진 뒤 Screen.SetResolution      ← 창이 튀는 게 안 보임
③ 2~3프레임 대기 (리사이즈 완료)
④ LoadSceneAsync(allowSceneActivation = false)
⑤ 최소 표시 시간(0.7초) + 로드 완료 → 씬 활성화
⑥ 페이드 아웃
```

- 오버레이는 DontDestroyOnLoad 캔버스(별도 씬 아님), 화면 전체 앵커
- 로딩 화면은 기획서의 부팅 DOS 연출과 통일 — `Launching 밭의_생존자.exe ...` + `[████░░░░]`
- 폰트: DOSGothic.ttf

### 실행 대상 배선
| 버튼 | 씬 | 해상도 |
|---|---|---|
| 홈 GAME START | Battle | 1280×720 |
| 늘어나라 pooo-tato | SnakeTitle | 1280×720 |
| 모아모아 10tato | MoaMoaTitle | 1920×1080 |
| 밭의 생존자 | GameStart0 | 1920×1080 |

> 해상도 값은 각 씬 Canvas 기준 해상도에서 추출한 추정치 — 인스펙터에서 확정 필요

## 5. 전투 코어 (§9)

### 플레이어 기본 수치
| 항목 | 값 |
|---|---|
| 최대 체력 | 60 |
| 에너지 | 2 |
| 턴당 드로우 | 5 |
| 손패 상한 | 8 |

### 방어 2종 분리 — 코어 훅
- 공격 방어(블록): 공격 피해를 수치만큼 상쇄. 중독은 무시. 소유자 턴 시작 시 소멸
- 효과 방어(와드): 새로 걸리는 디버프를 건수로 무효화

### 상태이상 6종
취약(+50% 피해) · 약화(−25% 피해) · 중독(턴 시작 피해, 방어 무시) · 힘 · 민첩 · 재생

### 턴 흐름
```
플레이어 턴 시작 → 에너지 리필 → 블록 소멸 → 중독/재생 → 드로우 5
  → 카드 플레이 (에너지 소모)
  → 턴 종료: 취약/약화 −1, 손패 버림
적 턴 → 블록 소멸 → 중독/재생 → 인텐트 실행 → 패턴 진행
```

### 적 6종 (몬스터 AI 시트 기준)
| 적 | HP | 공방 | 효방 | 패턴 |
|---|---|---|---|---|
| 흙덩이 | 15 | 0 | 0 | 공격5 → 공격5 → 내리치기8 |
| 껍질 두더지 | 15 | 6 | 0 | 웅크리기(방+5) → 공격5 → 공격5 |
| 포자 감자 | 15 | 0 | 2 | 포자(중독3) → 공격5 → 삭힌바람(약화2) |
| 밭두더지 | 18 | 5 | 0 | 파고들기(방+5) → 공격6 → 공격4 |
| 감자벌레 | 12 → 10 | 6 | 0 | 공격방어 0으로 깨지면 2페이즈 변신 |
| 허수아비(보스) | 30 | 0 | 1 | 경계(방+5) → 내려치기6 → 씨앗폭풍(약화2) → 공격8 |

## 6. 데이터 구조

### 2층 카드 스키마 (§8.2)
```
① CardData (SO 에셋)     — 원본 정의. 밸런싱 수치는 전부 여기 (§14.4 하드코딩 금지)
② CardInstance (세이브)  — 보유 카드 1장. 같은 카드도 개별로 다룸
     { instanceId, cardId, bound, upgrade }
```

### 저장 (PlayerPrefs)
| 키 | 내용 |
|---|---|
| tato_toin | 토인 |
| tato_instances | 보유 카드 인스턴스 |
| tato_deck | 런 덱에 든 instanceId 목록 |

### 런 덱 규칙
- 최소 8장 · 최대 30장
- 시작덱도 덱에서 뺄 수 있음 — 다른 카드로 8장을 채우면 시작덱 없이 진행 가능
- 시작덱의 유일한 특권은 귀속 = 판매 불가 (판매 기능은 미구현, 플래그만 준비)
- 새로 얻은 카드는 여유가 있으면 자동으로 덱에 포함

### 손실 채널 (§13.2)
| 채널 | 구현 |
|---|---|
| 런 실패 | 인게임 덱 소멸 — 덱에 있던 비귀속 카드는 컬렉션에서 영구 삭제 |
| 썩음 (§7) | 미구현 |
| 삭제 (§4) | 미구현 |

> 소멸 후 덱이 8장 미만이면 남은 보유분으로 자동 보충

## 7. 런 구조 (맵 / 스테이지)

### 맵 = 노드 그래프 (§11.3, 분기 최대 2)
- 가로 방향, 10열. 열별 노드 수: `1 · 1 · 2 · 2 · 2 · 2 · 1 · 2 · 1 · 1`
- 노드끼리 연결선을 그리고, 선으로 이어진 노드만 클릭 가능
- 2×2 구간은 35% 확률로 교차 → 길이 갈라졌다 합쳐짐
- 색: 지나온 길 초록 / 현재 주황 / 갈 수 있는 곳 파랑(보스 빨강) / 못 가는 곳 회색
- 각 노드에 적 이름(또는 `대장간 / 강화·제거`, `휴식 / +18`)이 미리 표시

| 열 | 내용 |
|---|---|
| 1 | 흙덩이 (고정 — 기본 주고받기 교육) |
| 2 | 껍질 두더지 (고정 — 공격 방어 교육) |
| 3~6 | 분기 전투 |
| 7 | 대장간 |
| 8 | 분기 전투 |
| 9 | 휴식 (체력 +18) |
| 10 | 보스 |

### 스테이지 3장
보스를 깨면 → 새 맵 생성 + 배경 전환 → 3스테이지 보스까지 깨면 런 클리어

| 단계 | 배경 | 체력 배율 | 공격력 배율 |
|---|---|---|---|
| 1 감자밭 | stageBackgrounds[0] | ×1.0 | ×1.0 |
| 2 뿌리층 | stageBackgrounds[1] | ×1.3 | ×1.2 |
| 3 깊은 토양 | stageBackgrounds[2] | ×1.6 | ×1.4 |

- 체력은 노드를 넘어 유지 (전투마다 초기화되지 않음)
- 런 상태는 메모리에만 유지 (§13.7 중간 저장 없음)
- 전투 중 `나가기` → 런처로. 런은 유지되어 다음에 이어서 진행

## 8. 보상 (§12.1)

승리 시:
- 토인: 일반 3~6 / 엘리트 12~15 / 보스 15~25
- 카드 3장 중 1택: 시작덱 제외 후보에서 희귀도 가중(일반 60% / 희귀 40%)
- 선택한 카드는 컬렉션에 인스턴스로 추가되고 런처 감자창고에 바로 반영

---

## 9. 대장간 (§11.2 · §10.10 · §10.8)

7번 노드. 런 덱 전체를 카드로 펼쳐 보여주고, 카드를 골라 작업.

| 행동 | 비용 | 효과 |
|---|---|---|
| 강화 + | 30 토인 | 피해·블록·효과방어 +3, 상태이상 스택 +1 → 이름에 `+` |
| 강화 − | 30 토인 | 코스트 −1 (최소 0) → 이름에 `−` |
| 제거 | 25 토인 | 컬렉션에서 영구 삭제 (덱 최소 8장 유지) |

- 카드당 강화는 1회 (§10.10)
- 강화는 인스턴스에 기록되어 다음 전투부터 반영
- 전투 덱 생성 시 강화된 인스턴스만 런타임 복제본으로 올림 → 원본 SO 에셋은 불변

## 10. 아트 적용 구조

### 핵심 규칙 — UiKit.Apply()
스프라이트를 넣으면 흰 틴트 + (Border가 있으면) 9-slice 자동,
비어 있으면 단색 폴백. → 아트를 하나씩 채워 넣어도 화면이 안 깨짐 (§14.4)

### 아트를 넣는 곳
| 대상 | 위치 |
|---|---|
| 스테이지 배경 3종 | BattleTheme.stageBackgrounds[0..2] |
| 카드 프레임(타입별)·코스트 배지 | BattleTheme |
| HP바·공격방어·효과방어 아이콘 | BattleTheme |
| 에너지 오브 | BattleTheme |
| 인텐트 아이콘 4종 | BattleTheme |
| 상태이상 아이콘 6종 | BattleTheme |
| 버튼 Idle/Hover/Pressed | BattleTheme |
| 카드 일러스트 | 각 CardData.artwork |
| 적 일러스트 | 각 EnemyData.artwork |

### 전투 화면 배치 (슬더스식)
```
[배경 전체]
   인텐트 + 적 패널(우상단)
   플레이어 패널(좌하단)
   에너지 오브        덱/버림 카운터
   [ 손패 카드 — 하단 중앙 ]        [턴 종료]
```
