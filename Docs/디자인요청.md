- 버튼·체력바 배경은 9-slice 테두리를 지정했다 (버튼 L80 B30 R86 T36 / 체력바 L24 B10 R26 T12).
  **다음 아트도 버튼·패널·바는 9-slice를 염두에 두고** 모서리 장식과 늘어나는 가운데를 나눠 그려주면 크기가 달라도 안 찌그러진다.
- 블록·효과 방어·상태이상 아이콘은 **오른쪽 빈 칸에 숫자**를 쓴다. 같은 형식으로 새 아이콘을 만들면 그대로 들어간다.
- 새 그림은 `Assets/Resorces/` 아래에 넣으면 자동으로 Sprite(Single)로 들어온다.
