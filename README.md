# tato.exe

**런처 형식을 가진 턴제 카드 로그라이크.**

가짜 OS 셸(`tato.exe`)을 켜면 미니게임 3종과 본편 카드게임이 깔려 있다.
미니게임을 플레이해 카드를 수급하고, 그 카드로 덱을 짜서 본편 로그라이크에 도전한다.

> Unity 6 (6000.6.0f1) · TatoGames · 프로토타입

---

## 무엇이 다른가

**① 카드에 수명이 있다.** 런을 거듭할수록 카드가 늙는다.
썩기 직전 한 런은 **싹**이 나서 오히려 강해지고(라스트 찬스), 그 다음엔 썩어서 못 쓴다.
"가장 센 카드가 곧 사라질 카드"라는 긴장이 덱빌딩의 시간축이 된다.

**② 방어가 누적된다.** 턴이 끝나도 방어가 남는다.
쌓아둔 흙을 `흙사태`로 터뜨려 공격으로 바꿀 수 있어서, 방어 빌드에 승리 수단이 생긴다.

**③ 미니게임이 카드 공급원이다.** 축이 하나씩 나뉘어 있다.

| 미니게임 | 장르 | 카드 축 |
|---|---|---|
| 늘어나라 pooo-tato | 스네이크 | 공격 |
| 모아모아 10tato | 스이카류 | 방어 |
| 밭의 생존자 | 농부 피하기 | 중독·뿌리 |

**④ 저장공간이 모자란다.** 미니게임을 전부 깔 수 없어서, 무엇을 설치할지가 곧
어떤 카드 축을 쓸지의 선택이 된다. 삭제하면 그 게임에서 얻은 카드도 사라진다.

---

## 게임 루프

```
[런처]  상점에서 미니게임 설치 → 미니게임 플레이 → 카드 수급
   │                                    ↓
   │                            감자창고에서 덱 편성
   ▼
[본편]  10노드 분기 맵 × 3스테이지
   │    전투 승리 → 토인 + 카드 3장 중 1택
   │    대장간(강화·제거) · 휴식 · 보스
   │    패배 → 인게임 덱 소멸 (귀속 제외)
   ▼
[런처]  토인·카드가 이어짐. 런이 끝나면 보유 카드가 한 살 먹는다
```

## 현재 상태

| 영역 | 상태 |
|---|---|
| 런처 셸 (7탭) · 미니게임 왕복 · 해상도 설정 | ✅ |
| 전투 코어 — 효과 15종, 적 6종, 3스테이지 | ✅ |
| 카드 29종 (시작덱 4 · 미니게임 15 · 전투 10) | ✅ |
| 감자 상태 (생/싹/썩음) · 카드 판매 | ✅ |
| 미니게임 → 카드 수급 | ✅ |
| 저장공간 · 상점 · 업적 · 패치노트 | ✅ |
| 밸런스 (시뮬레이션 기반 튜닝) | ✅ |
| **아트** | ⬜ 미착수 — 프로그래머 아트로 동작 |
| 다수 전투 (본체+소형) | ⬜ |

밸런스는 런 수만 번을 돌리는 시뮬레이션으로 맞췄다. 표준 플레이(대장간 강화 50% · 싹 20%)
기준 완주율 약 35%, 1스테이지는 강화 없이도 통과, 3스테이지는 강화를 다 해야 뚫린다.

## 실행

Unity 6000.6.0f1 로 열고 `Assets/Launcher/Scenes/Launcher.unity` 재생.

### 에디터 메뉴

데이터와 UI는 대부분 코드로 생성한다. 씬을 직접 편집하지 않는다.

| 메뉴 | 하는 일 |
|---|---|
| `TatoGames ▸ Generate MVP Cards (29)` | 카드 SO 29종 + `CardLibrary` 생성/갱신 |
| `TatoGames ▸ Card Game ▸ Build MVP Battle` | 적 6종 + 전투 씬 + 보상 풀 조립 |
| `TatoGames ▸ Build Launcher Shell` | 런처 셸 생성 (**탭 내용을 전부 날림** — 실행 후 아래 메뉴 필수) |
| `TatoGames ▸ Fill Tab Panels …` | 탭 내용 + HUD·전환·실행 버튼 배선 |

> 컴파일이 끝난 뒤에 메뉴를 실행할 것. 컴파일 도중 실행하면 옛 어셈블리가 돌아 배선이 빠진다.
